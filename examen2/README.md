# examen2

Proyecto básico con FastAPI y Docker.

## Requisitos
- Docker
- Docker Compose

## Levantar el contenedor
```bash
docker compose up --build
```

## Probar en navegador
- API: http://localhost:5055/
- Salud: http://localhost:5055/salud
- Docs Swagger: http://localhost:5055/docs

## Detener
```bash
docker compose down
```
